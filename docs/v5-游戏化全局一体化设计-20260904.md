# 词跃 LexiRise · 游戏化全局一体化设计（v5）

> 日期：2026-09-04　|　状态：待审批
> 背景：现有游戏化是"横向贴片"（各页各自奖励），缺乏**贯穿所有学习模块的因果主线**。
> 目标：让每个学习模块有专属的"游戏化身"与专属产出，且产出之间互相喂料——学什么，世界就变成什么样。

---

## 〇、调性校准（最重要的一节 · 初中生版，2026-09-04 补充）

**目标用户不是小学生，是初中生——12~15 岁，正在"变酷"的年龄。** 全案表达按以下红线执行：

### 铁律（必须遵守）
1. **克制优先**：每个页面最多 1 个游戏化视觉锚点（等级条 / 进度环 / 状态点三选一），**禁止堆叠**；动画时长 ≤1s；无满屏彩带、无儿童化喊话（"太棒了！""好厉害鸭！"全部禁用）。
2. **措辞走"秩序感"不走"幼稚感"**：用"掌握 / 进度 / 闯关 / 检验"这类中性词，不用"魔法 / 花园 / 冒险小岛 / 喂养小可爱"。
3. **反馈给数字和进度，不给表情包**：游戏感来自"因为做了什么 → 得到什么"的因果明细（数字可算），不来自卖萌。
4. **隐藏的丰富 > 表面繁华**：系统层可以有深度（金边/动作/称号），界面层保持素净——"有，但不往外堆"。
5. **强者语言**：称号/等级是"实力认证"（Lv、词霸、掌握度），不是"成长奖励"（幼儿式徽章感要淡）。

### 模块表达的初中生版（覆盖本文件其余章节的旧命名）

| 模块 | 旧表达（偏幼，作废） | 初中生版表达 |
| --- | --- | --- |
| 背书 | 关卡探索/探索中 | **单元闯关**：`Unit 3 · 进度 12/24`，通关=该单元 100%，仅一个完成标记，无横幅喊话 |
| 训练 | 修炼场/今日修炼 | **训练**：页头一行 `Lv.X · 今日还剩 N 词`（迷你等级条），完成后**结算明细**（数字可算） |
| 复习 | 照料花园/浇水 | **复习**：掌握度仪表（环）+ 答对浮 `+1 熟练`，消灭错词=计数+1 次动画（0.5s 内，不碎屏） |
| 测验 | 冒险挑战/副本 | **单元检验**：结果页星级评（★★★），为什么得这个分数可追究（错题明细已有） |
| 图鉴 | 收藏册/点亮魔法 | **图鉴**：保留（卡牌收集本身是初中生文化，中性），页面上就是"卡面+进度" |
| 宠物 | 喂食/照顾 | **跃跃 = 学习伙伴**：不说"喂食"，说"默契"（学习即默契+1）；宠物在场感占位，形象待定 |
| 宝箱 | 惊喜盒 | 保留"宝箱"，但触发文案克制（`收获结算`），不做跳跃旋转动画 |

### 因果链不变（机制是对的），变的只是"怎么说"：一切产出仍按 v5 第二章分配。

## 一、现状诊断（为什么"单一"）

| 模块 | 现状游戏化 | 问题 |
| --- | --- | --- |
| 训练 | combo/消灭错词/XP | 有反馈无叙事：没有"修炼变强"的因果感 |
| 背书 | 无（纯闪卡） | 新学一个词 = 图鉴该点亮、宠物该被喂食——**完全没接因果** |
| 复习 | 奖励闭环已接（答对+3/消灭+10） | 熟练度→金边的因果存在但 UI 不展示，用户感知不到 |
| 测验 | 分数→+20/+40 XP | 高分没有"荣誉感"产出（星星/称号），像考试不像冒险 |
| AI 学习 | 无 | 可以当"导师/图书馆"但没接入世界 |
| 统计 | 日历热力图（成人工具风） | 没有变成"冒险日志" |

**根因**：所有学习行为都只产出"同一个钱袋"（XP/金币），没有**行为→专属产出→专属成长的因果链**。

## 二、全局因果架构（核心设计）

### 2.1 一句话世界观

> **跃跃的世界 = 你的学习进度。** 你背的每一个词都在世界里留下真实痕迹：
> 新学的词 → 点亮跃跃的收藏册；练熟的知识 → 让跃跃长大；清除的错词 → 喂饱跃跃；考过的试 → 换来冒险星星。

### 2.2 五条因果链（每类行为吃"自己的产出"，产出之间互相喂料）

```
① 新学词（背书/今日新词）
   → 图鉴点亮 +1（收藏因果）＋ 宠物喂食 +10（喂养因果）
   → 集齐一套(20~30张) → +100币 + 单元徽章
   → 每点亮 50 张 → 跃跃学会 1 个新动作（收集反哺情感）

② 练熟词（训练/复习答对）
   → XP → 等级 → 称号（成长因果）→ Lv.5/12 → 跃跃进化
   → 训练期间 combo → 额外 XP（修炼因果）

③ 巩固词（复习/到期重练）
   → 熟练度 lv+1 → lv≥6 计入"已掌握" → lv≥7 图鉴金边（深化因果）
   → 金边一套 → 专属边框/限定皮肤（金边收集线）

④ 消灭错词（连对2次）
   → +10 XP ＋ 宠物额外饱食+10 ＋ 消灭动画（救赎因果）
   → 今日三件事"消灭错词"完成 → 每件 +15XP/+5币（已有）

⑤ 测验挑战（单元测验）
   → 得分评星：≥90=★★★(+40XP) · ≥75=★★(+30) · ≥60=★(+20)（挑战因果）
   → 星星累计 → 解锁称号档位/图鉴隐藏卡（荣誉收集）
```

### 2.3 因果的关键差异（这就是"不是每个板块各贴一个标签"）

| 行为 | 专属产出 | 专属产出流向 | 在界面上如何被看见 |
| --- | --- | --- | --- |
| 新学词 | 图鉴点亮 + 饱食 | 收藏册 / 宠物 | 背书页页头"本关新点亮 N 张卡" |
| 练熟词 | XP / combo | 等级 / 进化 | 所有学习页顶部常驻迷你等级条 |
| 巩固词 | 熟练度 / 金边 | 金边收集线 | 复习页"熟练度仪表"小环 |
| 消灭错词 | 喂食 + 动画 | 宠物饱食 | 消灭瞬间宠物开心表情 + 结算计数 |
| 测验 | 星星 | 荣誉/称号 | 测验结果页三星结算 + 星星累计条 |

## 三、每个模块的"游戏化身"与页面改造

### 3.1 背书页 → 「关卡探索」（最大改造，因果最重）

**隐喻**：每个单元 = 地图上一个关卡节点；背完单元内全部新词 = 通关。
**页面改造**：
- 页头：当前"关卡横幅"——`Unit 3 · 探索中 12/24 词` + 本关已点亮图鉴卡数 + 通关后"★ 关卡完成"盖章
- 背书过程中每个**首次认识**的词：卡片角落弹出"📖 图鉴 +1 · 跃跃 +10"淡入提示（首次=第 1 次答对）
- 全单元背完：弹出「关卡结算面板」：本关收获 = 新学 N 词 / 图鉴点亮 N / 喂养 +N / 获得 XP
- 单元进度已存在（数据有 grade/semester/unit），改造是**界面层 + 结算层**，不动数据结构

### 3.2 训练页 → 「修炼场」

**隐喻**：今日模式 = 每日修炼；答对 = 修炼生效（变强）；消灭错词 = 斩杀敌人。
**页面改造**：
- 页头叙事条：`⚔️ 今日修炼 · 还剩 12 词` + 迷你等级条（Lv.X + XP 进度，与首页一致的视觉语言）
- 进行中：宠物陪练位（右下角小宠物：答对冒爱心💗、答错皱眉🥺、combo 时欢呼）——宠物形象待定版先放占位圆形泡泡
- 轮次结束页（现有统计卡）升级为「修炼结算」：明细行（答对 ×N = +2N XP / 消灭错词 ×N = +10N / combo 奖励 / 本轮宠物饱食 +N / 升级提示）
- 现有 reward 逻辑全部复用，**只加结算展示层**

### 3.3 复习页 → 「照料花园」

**隐喻**：到期复习 = 给记忆浇水；熟练度 = 植物生长；错词本 = 待清除的杂草敌人。
**页面改造**：
- 页头加"熟练度仪表"：一个进度环显示 总词/学习中/已掌握 分布（数据已有 memory.distribution）
- 消灭错词时宠物表情联动（已接 reward，补 UI 表现）
- 复习答对各词 = 熟练度 +1 的**可见反馈**（在卡片右上角浮现 "+1 熟练"微标；熟练度≥6 时显示"已掌握 ★"）

### 3.4 测验页 → 「冒险挑战」

**隐喻**：测验 = 副本出征；得分 = 战果评星。
**页面改造**：
- 页头：`⚔️ Unit 挑战` 横幅 + 当前星星数（累计）
- 结果页：三星/二星/一星评星动画 + 奖励明细（分数→XP、拆出"星星 +1/+2/+3"）+ 宠物庆祝（占位）
- 星星累计存 game 字段（新字段 `stars`，为称号档位/隐藏卡预留）

### 3.5 AI 学习 → 「导师书斋」
- 轻量：复习包/练习页加一行"导师寄语"叙事（生成后：`📚 笔记整理完成`），不重做画面

### 3.6 统计页 → 「冒险日志」
- 轻量：标题行叙事化（`📖 冒险日志 · 连续 N 天`），热力图保持（它其实是最有用的成人向数据，不牺牲功能只换叙事壳）

## 四、贯穿性全局组件（游戏感的来源，不只是各页贴片）

| 组件 | 作用 | 出现位置 | 状态 |
| --- | --- | --- | --- |
| **迷你等级条** | XP/Lv 全局可见，因果"我正在长到哪" | 首页 hero（已有）+ 训练/背书/复习/测验页头 | 新做（复用 game.state()） |

| **星星累计条** | 测验荣誉可见 | 测验页头 + 成就页 | 新做（game.stars） |

## 五、与现有实现的关系（已有哪些基础）

- ✅ 奖励结算引擎（game.reward 唯一入口）——因果的"钱袋子"已统一
- ✅ 首答双倍 / combo / 消灭错词 / 每日任务 / 宝箱——机制已有
- ✅ 图鉴点亮推导（lv≥3/≥7）——成就页已算，背书/训练页直接引用
- ✅ 熟练度数据（memory.lv）→ 背书关卡进度、金边都零冗余推导
- ⚠️ 宠物形象未定（冻结中）→ 陪练位先用占位，不影响架构
- ➕ 需新增：game.stars（测试星星）、结算面板组件、迷你等级条组件、各页头部叙事条

**原则**：不新增数据表/同步字段以外的复杂度——一切产出依然只存 game/memory，页面只做"世界表达"。
