# 侧边栏改造方案（配色收口 + 去幼稚化）

> 状态：**待你挑方向**，挑完我先出 demo 页面对比，再落地。
> 本文所有"实测"结论都有行号出处，不是印象。

---

## 一、诊断：为什么侧边栏看起来"幼稚"、又和整体配色不一样

### 1. 13 个图标全是 emoji（主因）

`app/components/Sidebar.jsx` 第 16–35 行：

```
🏠 首页   🎯 训练   🔁 复习   📝 单元测验   📖 背书
🏆 成就   ✨ AI 学习  📈 统计
📚 词料库  ⚙️ 设置    ⚙️ 管理后台
👤 用户名  🔐 登录
```

emoji 有三个致命问题，跟"克制"天生对立：

1. **它是彩色的**。`globals.css` 第 1–20 行的纸墨 token 只有米白纸（`#f4f0e6`）、墨黑（`#26221d`）、朱砂红（`#e4572e`）三个主色。13 个 emoji 一次性往侧边栏里塞进十几种高饱和色，**配色打架的根源就在这**——不是 CSS 没调好，是图标本身不受 CSS 控制。
2. **它的长相不由你决定**。Windows 上是 Segoe UI Emoji，安卓是 Noto Color Emoji，iPhone 是 Apple Emoji——同一个页面在三台设备上是三套风格。所以"风格统一"这件事从根上做不到。
3. **它默认是卡通圆胖的**。这是"幼稚"评价最直接的来源。

### 2. 两个按钮用的是文本字符，不是图标

- `Sidebar.jsx` 第 88 行：汉堡按钮是 `☰`（U+2630）——在部分系统上会被渲染成 emoji 变体，大小和基线也随字体漂。
- 第 97 行：折叠按钮是 `«`——这是**书名号/双角引号**，不是"收起"图标。它表示的方向语义是错的。

### 3. 侧边栏里还留着上一代"绿色主题"的颜色（这是"配色不一样"的直接证据）

v6 换肤把主色改成了纸墨，但侧边栏和底部栏有几处漏网，还是旧的绿/粉色：

| 位置 | 现在的值 | 问题 | 应改为 |
| --- | --- | --- | --- |
| `.sb-foot`（第 322 行） | `#9fb0ab` | 灰绿色，不是暖灰 | `var(--text-soft)` |
| `.sb-login:hover`（第 1969 行） | `#e3f1eb` | 薄荷绿 | `var(--surface-2)` |
| `.sb-logout:hover`（第 1958 行） | `#b23b3b` / `#e89a9a` | 粉红，不是朱砂 | `var(--stamp-red)` |
| `.btab` 阴影（第 2786 行） | `rgba(15,110,86,.08)` | 深绿投影 | 去掉，或墨色 6% |
| `.lexi-tab.on`（第 2762 行） | `rgba(29,158,117,.3)` | 绿色投影（已被 v6 层盖掉，但代码还在） | 删 |

同类旧色全站还有 **37 处**（`#1d9e75` 绿、`#2bc08c`、`#ffb84d` 橙、`#e3f1eb`…）。侧边栏不是孤例，只是最显眼。

### 4. 品牌位是真实宠物照片，旁边全是卡通 emoji

`.sb-logo` 放的是 `PetImage`——**真实的宠物照片**，这是站点的品牌资产。一张写实照片紧挨着十几个彩色卡通 emoji，是两种完全不同的视觉语言，割裂感就是这么来的。

## 二、四个方向（可单选，也可组合）

### 方向 A：单色线描图标（最稳、最低风险）

- **做法**：新建 `app/components/Icon.jsx`，内联 SVG，`stroke="currentColor"`、`stroke-width` 1.6、圆头端点、24×24 网格。`.sb-icon` 从 `font-size:20px` 改成 `width/height:20px`，颜色自动继承文字色。
- **图标对应**：首页 home／训练 target／复习 rotate／测验 file-check／背书 book-open／成就 award／AI sparkle／统计 bar-chart／词料库 library／设置 sliders／管理 shield／折叠 chevron-left／汉堡 menu／用户 user／登录 log-in。
- **优点**：全球 App 的通用语言，一眼就"成年"；颜色 100% 受 CSS 控制，配色问题当场消失；零依赖（手写 path，不装图标库）。
- **代价**：要写约 15 条 path；辨识度依赖符号选得对不对。
- **幼稚度**：0。
- **风险**：可能"太普通"，没有品牌个性。

### 方向 B：汉字印章导航（最有辨识度）

- **做法**：每个菜单项左边一个 24×24 小方框，里面一个汉字。未选中＝墨线细框＋墨字；选中＝朱砂底白字（或墨底纸色字），像盖章。纯文字＋边框，比 SVG 还好实现。
- **选字**：首页「首」／训练「练」／复习「复」／测验「测」／背书「诵」／成就「勋」／AI「智」／统计「计」／词料库「典」／设置「设」／管理「管」。
- **优点**：和"纸墨＋印章"这套 identity **同源**，不是外挂的风格；汉字单字自带书卷气，跟"幼稚"是反方向；辨识度独一无二。
- **代价**：一个字要能让人秒懂（「典」「计」需要配文字才清楚，好在旁边就是标签）；有些概念一个字概括不了。
- **幼稚度**：0，且有格调。
- **风险**：用户可能需要一两天适应，不如图形直观。

### 方向 C：杂志目录式（去掉图标，用序号和排版）

- **做法**：不要图标。分组标签（学习／发现／工具）保留小字大字距；每项＝项名＋右侧极淡的两位序号（`01` `02` `03`…，全站连续编号）；选中态＝左侧 3px 朱砂竖线＋项名加粗＋序号转朱砂。
- **优点**：最"杂志"、最克制；完全没有图形语言，**不可能幼稚**；信息密度高，一屏能看清全部入口。
- **代价**：失去"扫一眼认路"的图形提示；手机抽屉里纯文字略显单调。
- **幼稚度**：0。
- **风险**：改动最大，侧边栏的"性格"会整个换掉。

### 方向 D：A＋B 混合（**我推荐**）

- 主图标用**线描**（方向 A），保证扫视效率；
- 但用**印章语言做强调**：选中项左侧 3px 朱砂竖条，分组标签左边一个小朱砂方点，品牌位的宠物照片边框保持墨线＋硬阴影；
- 配色统一到 token，清理上面第 3 节的 5 处旧色（顺手清全站 37 处里的高饱和绿/橙）。
- 理由：A 解决"幼稚"和配色失控，B 解决"没品牌个性"，两者不冲突——线描负责形状，印章负责颜色和状态。

---

## 三、顺带必须做的一件事：配色收口

不管选哪个方向，这五处旧色都要换掉，否则侧边栏永远和整体"差一点"。建议同时做一次全站扫色：把高饱和的旧绿（`#1d9e75`/`#2bc08c`/`#159a71`/`#35b96a`）和旧橙（`#ffb84d`/`#ff8a3d`）归到 `--stamp-green: #2f7d4f` / `--stamp-red: #e4572e` / `--hl: #fff3a0` 三个 token 上。

## 四、执行顺序（挑完方向后）

1. **出 demo**：一个对比页面，三/四个方向并排、用真实的菜单文案和真实颜色 token 渲染。你看实物挑，不看描述猜。
2. **落地 Icon.jsx 或印章样式**：只改 Sidebar + BottomTab（手机底栏共用同一套图标，必须一起换，否则手机和电脑两套风格）。
3. **配色收口**：按第三节改 token。
4. **验证**：390px 手机抽屉＋1280px 桌面、展开态＋折叠态、选中态＋hover 态，各截图对比；确认 `☰`／`«` 换成 SVG 后不再随字体漂。
5. 记 `DEVELOPMENT-LOG.md`。

## 五、验收标准（怎么算"不幼稚了"）

- 侧边栏里除了品牌位的宠物照片，**不应再有任何不受 CSS 控制的颜色**。
- 全站色值能数得过来：米白纸、墨黑、暖灰、朱砂、松绿、高亮黄，六个。
- 手机底栏和桌面侧边栏是**同一套图标**。
- 遮住文字只看图标，仍然认得出每个入口（方向 C 除外，C 靠文字）。
