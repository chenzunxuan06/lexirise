# 首页方案 B · 暖萌宠物风 —— 细化设计规格（2026-09-04）

> 状态：待用户审批（配套原型：`首页方案B-暖萌宠物风-demo.html`，浏览器可直接打开）
> 方向定位：**首页 = 跃跃的房间**。学习入口是"带宠物去上课"，收藏/徽章/图鉴是"跃跃的收藏架"。
> 与方案 A 的关系：A 是"干净的 App"，B 是"有生命的陪伴"。B 保留 A 的全部结构决策（首屏 3 决策点、任务卡合一、快捷格删除），只替换视觉语言与情感层。

---

## 一、一句话设计理念

> **不是"打开一个背单词 App"，而是"回到跃跃在的房间，带它去上课"。**
> 所有界面元素都长在"房间"隐喻上：主按钮=出门上课的门；每日任务=今日菜单/日程牌；图鉴=跃跃的收藏册；成就=奖杯架；商城=跃跃的衣橱。

## 二、视觉语言（完整令牌）

### 2.1 色彩（暖奶油底 + 蜜桃橙 + 抹茶绿 + 奖励金）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--bg` 奶油纸底 | `#FBF3E5` | 全站底色（纸感，微噪点纹理） |
| `--card` 奶白卡 | `#FFFDF7` | 卡片/任务行/弹层 |
| `--ink` 暖棕墨 | `#4A3F35` | 正文（暖调黑，不刺眼） |
| `--ink2` 浅褐 | `#9C8774` | 次要文字/说明 |
| `--peach` 蜜桃橙 | `#FF8A4C`（深 `#F2703B`） | 主按钮/宠物主色/交互高亮 |
| `--leaf` 抹茶绿 | `#8FBF6E`（深 `#6FA85C`） | 成功/打勾/已掌握/复习类 |
| `--gold` 奖励金 | `#FFB84D`→`#FF9A3D` 渐变 | 宝箱/金币/徽章/进化 |
| `--blush` 腮红粉 | `#FFC9BC` | 宠物腮红/点缀/新手引导 |
| `--line` 燕麦线 | `#EFE0CC` | 1px 描边（全部用暖线，禁冷灰） |
| 阴影 | `0 8px 24px rgba(197,150,90,.16)` | 一律暖阴影 |
| 圆角 | 卡片 20px / 按钮 24px / 胶囊 999px | 全站统一 |

**高对比保障**：正文 ink 与奶油底对比度 ≈ 8:1（满足可读性）；按钮白字压桃橙 4.5:1 达标。**禁冷色**：蓝、灰蓝、纯黑一律不出现（AI 讲解等中性场景用"墨绿+奶油"的暖中性替代）。

### 2.2 字体与字重
- 全站中文：`PingFang SC / Microsoft YaHei / system-ui` 圆润档（demo 不引外部字体，正式版若允许引 Google Fonts 可加 `Baloo 2` 做数字/英文标题）。
- 字号阶梯（保持七级）：11 标签 / 12.5 辅助 / 13.5 正文 / 15 卡片标题 / 18 区块标题 / 22 页面标题 / 28 大数字。
- 数字与 XP/金币用 **900 字重 + 0.5px 字距**，营造"游戏数值感"。

### 2.3 图形语言（手绘感，不 AI 感）
- **描边**：2px 圆头暖棕线 `#5B4636` 只用于插画与贴纸（0.6 透明），UI 控件不用描边、用填充+阴影。
- **贴纸元素**：云朵 ☁、单词气球 🎈（doodle SVG）、印章（旋转 8° 的"已完成/消灭"章）、圆点底纹、铅笔小标。
- **禁止**：棱角渐变方块、荧光色、玻璃拟态（毛玻璃只用于想念剧情遮罩一层）。

### 2.4 动效语言（统一缓动 `cubic-bezier(.34,1.35,.5,1)`）
| 动效 | 参数 | 触发 |
| --- | --- | --- |
| 宠物漂浮 | 上浮 4px，2.8s 循环 | 常驻 |
| 眨眼 | 眼睛 scaleY→0.1，0.18s，每 3.5~5s 随机 | 常驻 |
| 耳朵抖动 | 左耳 rotate ±8°，0.4s | 点击宠物时 |
| 尾巴摇摆 | 尾尖 rotate ±10°，1.6s | 开心心情时 |
| 打勾弹跳 | 勾号 pop 0.45s | 任务完成 |
| 宝箱呼吸 | 光晕放大缩小 2.2s | 可开箱时 |
| 开箱爆发 | 抖动 0.3s + 金币/星星粒子 0.8s | 开箱 |
| 消灭错词 | 词卡碎裂（错词页） | 措辞消灭 |
| 升级/进化 | 全屏粒子+剪影亮相 1.8s | Lv 提升/形态进化 |
| 想念剧情 | 全屏暖暗渐显 0.6s | 断签 2 天以上首开 |

## 三、宠物「跃跃」角色设定（B 方向的心跳）

### 3.1 性格与语气
- 性格：软糯、粘人、爱记单词。说话短句 + 语气词："今天也要一起加油鸭～""错词不可怕，消灭它们！"
- **语气规范**：≤18 字/条；每条带学习引导（设计原则 1：鼓励语=学习引导，不纯卖萌）；emoji 每句 ≤1。

### 3.2 三形态 × 三心情（SVG 一套组件出 9 态）

| 形态 | 解锁 | 特征 |
| --- | --- | --- |
| 幼狐 | 默认 | 圆脸+大耳朵+腮红+小短腿，**围脖奶油白** |
| 少年狐 | Lv.5 | 大一圈、**橙红渐变围巾**、尾巴更蓬 |
| 词霸狐 | Lv.12 | 体型最大、**金色小皇冠**、眼带自信弧线 |

| 心情 | 表现 |
| --- | --- |
| 开心（饱食≥70） | 眯眼笑（︶ 弧）+ 尾巴摆 + 头顶冒小心心 |
| 平常（30~69） | 圆眼睛 + 微笑 + 偶尔眨眼 |
| 挨饿（<30） | 下垂眼 + 嘴角撇 + 飘"我饿了 🥺"气泡（**不谴责、不惩罚**） |

### 3.3 交互与"对话"（情感驱动脚本）
| 交互 | 行为 | 文案示例 |
| --- | --- | --- |
| 点击跃跃 | 随机鼓励语 + 耳朵抖动 | "Unit 3 还差 4 个词哦" |
| 完成任务时 | 跃跃在任务卡右上角鼓掌（小图） | — |
| 连对 3/5/10 | 跃跃头顶冒"🔥 x5" | — |
| 消灭错词 | 跃跃挥爪 + 碎裂动画 | "消灭 +1！它不会再来烦你啦" |
| 断签 2 天 | 全屏举牌"我想你了 🥺"（可关） | "回来背几个词吧，我等你" |
| 断签 7/14/30 天 | 牌面升级文案四档 | "你还好吗…我们从 Unit 5 捡起来吧" |
| 升级 | 全屏粒子 + 新形态剪影亮相 | "Lv.5！我长大啦 🎉" |
| 进图鉴集齐一套 | 跃跃翻收藏册给你看 | "这一套我帮你收好啦～" |

### 3.4 宠物页（新增 `/pet`，B 方向延伸）
大图（九态）+ 饱食/心情条 + 名字可改（引导期可改一次，之后金币改名卡）+ 进化记录时间线 + 装扮试穿位 + 成长日记（每日一条"跃跃日记"：今天消灭 3 个错词，它开心地摇尾巴）。

## 八、验收标准（视觉一致性走查表）

1. 全站无冷灰色边框/阴影（grep 禁色号清单为空）。
2. 无 emoji 出现在导航/按钮/图标位（SVG 组件覆盖）。
3. 首屏 375px：③主按钮在任何页面首屏可见；决策点 ≤3。
4. 宠物九态在首页/宠物页/成就页渲染正确，动效帧率 ≥50fps。
5. 全部文案走"跃跃语气规范"（≤18 字/条、≤1 emoji、每条带学习引导）。
6. 想念剧情、进化、开箱三大仪式在正式数据下可完整触发一遍。
