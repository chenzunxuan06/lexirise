# 词跃 LexiRise · 游戏化设计方案 v1

> 状态：已与用户对齐方向（2026-09-02）：情感驱动宠物养成 + XP/金币经济 + 图鉴收集（方案乙）。
> 本文档是 P1-4 / P1-5 / P1-6 三个任务的实施规格。前置条件：P0 阶段（首页 D / 训练默认化 / 新手指引）已完成。

---

## 一、设计目标与原则

**目标**：让初中生"为了跃跃回来"，而不是"为了分数坚持"。

三条原则：
1. **奖励依附学习**：所有游戏化产出必须由真实学习行为（答题/复习/测验）产生，不允许签到白嫖以外的纯点击收益。
2. **永不惩罚过度**：不学最多宠物挨饿卖萌，绝不扣 XP/降级/清空——挫败感是流失之源。
3. **每日收益封顶**：XP/金币每日软上限，防刷也防沉迷（详见 §3.2）。

---

## 二、核心循环

```
学习行为（练词/复习/错词/测验）
   │  产出 XP + 金币 + 图鉴点亮
   ▼
宠物「跃跃」成长 / 进化  ←── 情感钩子（它需要你）
   │
   ▼
金币商城：皮肤 · 宠物装扮 · 补签卡
   │
   ▼
展示与炫耀：hero 区装扮、成就墙、图鉴册
   │
   ▼  （好看/被同学看到 → 想继续）
回到学习行为
```

## 三、玩法明细

### 3.1 XP 与等级

| 行为 | XP |
| --- | --- |
| 答题答对 | +2 |
| 复习词答对 | +3（复习价值更高） |
| 错词"消灭"（连对 2 次移出错题本） | +10 |
| 完成每日三件事（每件） | +15 |
| 单元测验 ≥60 分 | +20；≥90 分 +40 |
| 新手指引完成 | +30 |

- 等级曲线：`Lv(n) 所需累计 XP = 50 × n²`（Lv.5≈750，Lv.10≈5000，一学期可冲 Lv.12~15）
- 称号：Lv.1 单词新手 → Lv.5 词汇学徒 → Lv.10 单词达人 → Lv.15 词汇宗师 → Lv.20 词霸
- 展示位：首页 hero 徽章 + 排行榜 + 成就页

### 3.2 金币经济

- 产出：每日三件事各 +5 币；宝箱 +5~50；成就 +20~100；图鉴集齐一套 +100
- 消耗：皮肤 80~200 币、宠物装扮 60~150 币、补签卡 50 币
- **每日 XP 软上限 200 / 金币软上限 60**：超出后照常学习但不再产出（提示"今天收获满满，明天继续"）
- 防通胀：商城价格按"日均产出 × 3~5 天"定价，一件皮肤约需 3~5 天积累

### 3.3 宠物「跃跃」（情感驱动核心）

**状态机**（存 `game.pet`）：
- `hunger` 饱食度 0~100：每次学习行为 +10（上限 100），每日 04:00 -30
- `mood` 心情：hunger≥70 开心 / 30~69 正常 / <30 挨饿（蔫蔫的，但不死）
- `stage` 形态：幼狐（默认）→ 少年狐（Lv.5 进化）→ 词霸狐（Lv.12 进化），进化时全屏动画
- `outfit` 装扮：商城购买，永久拥有

**交互**：
- 住在首页 hero 区（不是静态图标）：开心时漂浮/眨眼，挨饿时趴下+气泡"我饿了，背几个词吧"
- 点击跃跃：随机鼓励语（"今天 Unit 3 还差 4 个词哦"）——**兼做学习引导**
- 断签提醒：连续 2 天未学，下次打开时跃跃举牌子"我想你了 🥺"（不做 push 推送，不打扰）

### 3.4 每日三件事 + 宝箱

- 三件事 = 复习到期词 / 消灭错词 / 新学词（与首页"今日三件事"卡一一对应，完成即打勾动画）
- 全部完成 → 开宝箱（转盘/翻牌动画 1.5 秒）：金币×5~50（60%）、皮肤碎片×1（25%，3 碎片合成指定皮肤）、补签卡（10%）、限定徽章（5%）
- 碎片机制保证"连开 3 天必有实质奖励"，避免纯随机挫败

### 3.5 combo 连对

- 训练/复习中连对 3/5/10 题：全屏轻量特效（彩带 + "+combo x5"）+ 音效（可关）
- 连对 10 题额外 +5 XP（计入每日上限）
- 答错立即中断，不清已有 XP

### 3.6 图鉴收集册（方案乙）

- **载体**：1535 词 = 1535 张图鉴卡，按"年级-册-单元"分为 60 套（每套 20~30 张）
- **点亮规则**：词达到记忆曲线 lv≥3（学习中后期）→ 点亮普通卡面；lv≥7（已掌握）→ 升级为金边卡面
- **卡面内容**：单词 + 音标 + 释义 + 词根词缀/例句（复用现有数据，点击卡片看详情+朗读）
- **集齐奖励**：一套全点亮 → +100 币 + 该单元纪念徽章；一册全金边 → 限定皮肤
- **展示**：图鉴页（套卡封面墙 → 点进去翻卡），首页 hero 显示收集进度（"已点亮 312/1535"）
- **与宠物联动**：每点亮 50 张，跃跃学会一个新动作（展示动画）——收集反哺情感线

### 3.7 成就徽章（首批 24 个）

- 学习量：首次学习 / 累计 100 / 500 / 1000 / 1535 词
- 坚持：连续打卡 3 / 7 / 30 / 100 天
- 质量：单轮全对 / 测验满分 / 错词本清零 / 单日 100 词
- 单元：首个单元通关 / 每册通关 ×6
- 收集：首套图鉴集齐 / 10 套集齐 / 全图鉴
- 特殊：首次进化 / 首次购买皮肤 / 首次分享家长周报

### 3.8 补签卡与赛季榜（后期）

- 补签卡：断签后 3 天内可用 1 张修复连续天数（商城 50 币，宝箱可开出）
- 赛季排行榜（P2 再做）：XP 周榜，分"好友/同年级"两个范围，周一清零；前 3 名得限时头像框

## 四、数据模型

### 4.1 user_data 表新增 `game` 字段（JSON，随 sync 整包同步，无需 ALTER）

```json
{
  "xp": 520, "coins": 45,
  "dailyXp": { "2026-09-02": 120 },      
  "pet": { "hunger": 80, "mood": "happy", "stage": 1, "outfit": "default",
           "lastFed": 1756800000000, "actions": ["jump"] },
  "streakProtect": 1,
  "skins": ["default"], "currentSkin": "default",
  "chestFrags": { "skin_fox_red": 1 },
  "badges": ["first_study", "streak_7"],
  "albumGold": [],
  "chestLastDate": "2026-09-02"
}
```

- 图鉴点亮状态**不单独存**——由现有 memory.js 的 lv 值实时推导（lv≥3 点亮 / ≥7 金边），零冗余
- `dailyXp` 只保留最近 7 天键，防膨胀
- 游客：game 存 localStorage，登录后随 sync 合并（XP 取大者，皮肤/徽章取并集）

### 4.2 events 打点表（P1-4 一并建）

```sql
CREATE TABLE IF NOT EXISTS events (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER,            -- 游客为 NULL
  event TEXT NOT NULL,        -- page_view / train_start / train_done / exam_done / chest_open / pet_evolve ...
  meta TEXT DEFAULT '{}',
  ts INTEGER NOT NULL
);
CREATE INDEX idx_events_ts ON events (ts);
```

客户端批量缓冲（10 条或 30 秒）POST `/api/events`；游客数据仅用于聚合统计。

## 六、实施拆分（对应任务列表）

- **P1-4 数据层**：game 字段读写（lib/memory.js + lib/sync.js 合并逻辑）+ events 表与上报 API + 游客/登录合并 → 0.5 轮
- **P1-5 核心循环**：XP/金币结算器（唯一入口 `reward.js`，所有学习行为调用）+ 跃跃状态机与首页形象 + 三件事宝箱 + combo 特效 → 2 轮
- **P1-6 图鉴与成就**：图鉴页 + 点亮推导 + 成就判定器（事件驱动，listen reward/事件流）+ 成就页 → 1.5 轮

## 七、健康设计

- 每日产出软上限（§3.2）
- 无无限抽奖、无付费、无攀比性全服榜（仅小范围周榜）
- 断签只有"跃跃想你"的温情提醒，无惩罚推送
