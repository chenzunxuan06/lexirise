# 词跃 LexiRise · 纸墨风格落地计划（v6）

> 依据：D2×D3 融合 demo 已获用户批准（`风格探索D2-融合-demo.html`）
> 原则：功能逻辑零改动（奖励/同步/打点/数据结构全部不动），纯视觉换肤

## 一、范围

| 内容 | 做法 |
| --- | --- |
| 全局 token | `:root` 变量重赋值：纸底 / 纸卡 / 墨 / 章红 / 章绿 / 硬阴影 / 小圆角 |
| 深色模式 | `[data-theme=dark]` 变量同步重赋（暗纸墨） |
| 通用类换肤 | 按钮/卡片/输入/Tab/徽标/进度/弹层 —— 在 globals.css 末尾追加"覆盖层"（append-only，便于回滚） |
| 首页 hero 区 | 绿渐变 hero → 纸卡描边 + 硬阴影（保留宠物位与全部内容） |
| 复习页细节 | 错词"错×N"红章、连击/消灭 toast → 荧光胶囊/红章 |
| 训练页细节 | 今日模式卡加胶带、答题选项纸卡选中绿、进度黑缝、结算面板纸卡+印章 |
| 其余页面 | 通用类自动换肤 + 个别刺眼硬编码（rowbar/album 渐变）收敛 |
| PWA themeColor | layout.jsx #1d9e75 → 墨色 |

## 二、明确不做（本轮）

- emoji → 线性 SVG 图标系统（量大，单独一轮）
- 宠物形象（冻结中）
- 首页两列/布局再调整
- admin 后台换肤（运维工具保持朴素）
- 图鉴橙渐变等低频残留色（记入反思清单，微调不阻塞）

## 三、执行步骤（一口气做完，最后统一验证+反思）

1. PLAN 文档（本文件）
2. `globals.css`:root 重赋 → 3. dark 重赋 → 4. 末尾追加纸墨覆盖层（~250 行）
5. `layout.jsx` themeColor → 墨
6. `npm run build`
7. 无头 CDP 验证：body 底色 / hero / 按钮 / 复习红章 / 训练胶带卡 的实际计算样式
8. 反思：残留违和清单 + 待用户裁决项，输出

## 四、验证点（完成时逐项核）

- body 背景 = #f4f0e6 横线纸
- 首页 hero = 纸卡描边（非绿渐变）
- .start-btn 计算背景 = 墨黑
- 复习页 .badge.err = 红章（旋转）
- 训练页 .daily-entry 有胶带伪元素
- .combo-toast/.clear-toast 非渐变胶囊
- 深色模式变量生效（切 data-theme 检查）
- build 0 错误、无布局回归（CDP 几何抽查首页 hero/goal 间距）

## 五、回滚方式

删除 globals.css 末尾"纸墨覆盖层"块 + 还原 :root 与 layout themeColor 两处 edit 即可全量回退。
