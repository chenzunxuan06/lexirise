## 一、总体结论

v2 的骨架（首页改版 / 训练今日模式 / 新手指引 / game 数据层 / 打点 / 分享）是立住的，**但"游戏化闭环"只完成了 60%**：

- **激励链路断裂**：复习页零奖励、task_done 无人调用 → 孩子从首页点进最需要鼓励的行为，却拿不到任何反馈；
- **玩法缩水**：图鉴从"套卡墙+翻卡+套系奖励"缩成一根进度条；宠物页、商城、补签卡消费、碎片合成均未落地；
- **导航不一致**：测验/AI 练习两个页面没有侧边栏入口，且 AI 双入口互相割裂——旧问题复现；
- **存在 3 个实打实的 bug**（徽章永远拿不到、幸运星徽章不显示、金币上限无提示）；
- **视觉无统一叙事**：色彩/图标/字号/圆角各区块各说各话，是"丑"的根源。

## 三、问题分级

### P0 · 硬伤（bug / 激励断链，改完立刻见效）

1. **复习页零奖励**：`/review` 全流程接入 `game.reward()`（答对 review +3、连对 combo、消灭错词 +10），与训练页行为完全一致。→ 统一"所有学习行为必须走 game.reward，禁止绕过"（设计文档 §六"唯一入口 reward.js"落地为代码规约）。
2. **task_done 无人调用**：首页"今日三件事"每完成一件即结算 `reward("task_done")`（+15XP/+5币）并打勾动画联动。
3. **徽章 bug ×2**：`refreshAchievements` 调用补传 `level`；`chest_lucky` 徽章要么加入 ACHIEVEMENTS 列表，要么从 openChest 移除改发其它可显示奖励。
4. **上限提示**：`reward()` 返回 `capped` 后，由统一奖励 Toast 展示"今天收获满满，明天继续 🏡"；金币截断同理。
5. **等级/进化/徽章即时反馈**：升级、进化（Lv.5/12）、新徽章获得——统一事件驱动弹层（`game` notify 里带 delta 或页面监听），首页/训练/成就都要能触发，不再只是静默。

### P1 · 玩法衔接（设计承诺的补全）

6. **图鉴做完整**：新增 `/album`（或成就页内独立 Tab）：
   - 套卡封面墙：按 年级-册-单元 60 套分组（数据已有 grade/book/unit 字段），每套显示点亮进度；
   - 翻卡视图：卡面 = 单词+音标+释义+词根/例句+朗读（复用现有数据与 tts）；lv≥3 点亮、≥7 金边；
   - 套系奖励：集齐一套 → +100币+纪念徽章（新增徽章入 ACHIEVEMENTS））；整册全金边 → 限定皮肤占位；
   - 首页 hero 补"已点亮 N/1535"进度；词库/单词卡提供"去图鉴看这张卡"跳转。
7. **宠物页**：`/pet`（或首页浮层）——大图、心情/饱食度实时显示、改名（现在只有新手指引能改一次）、进化记录、未来的试穿位。
8. **经济闭环**：本期不做商城的话，至少给出金币/碎片出口：碎片 3:1 兑换金币或直兑第一个皮肤；补签卡在 `stats` 打卡区加"使用补签卡"按钮（断签 3 天内可用，修 streak 天数）。
9. **徽章扩充到设计口径**：补齐 单元通关 / 每册通关×6 / 首套/10套/全图鉴 / 首次分享周报 / 首次购买 等，与 ACHIEVEMENTS 定义、墙渲染、奖励金币三处一致。

### P2 · 导航与信息架构（你指出的"页面没进侧边栏"）

10. **侧边栏重排**（在"导航减法"原则下做加法而非放回去）：
    - 建议结构：首页 / 训练（今日模式） / 复习 / 单元测验 / 成就（等级·图鉴·徽章合一，已如此）/ 词库 / 短语 / 词根词缀 / AI 学习 / 统计；
    - **测验进侧边栏**（它是五大核心学习入口之一，现在只能从首页快捷格进，等于藏起来了）；
    - **AI 双入口合一**：`/practice?auto=1` 与 `/ai` 合并为一个"AI 学习"（练习模式作为 /ai 内的一个 Tab，或反向）；删掉重复入口，保留直链重定向，避免旧链接 404；
    - `/mywords` 维持"页面保留、不在导航"（直链可访问，家长/老师端预留）。
11. **全站互链审计**：用 href 清单对照侧边栏+首页快捷格，补齐所有"页面存在但无入口"的路由（exam/practice 之外是否还有孤儿路由）；关键页面加"返回"链路；首页快捷格 6 项与侧边栏语义一致化（去掉"自由训练"与"AI 练习"这类切换式文案）。

### P3 · 视觉系统 v2（治"丑"的根：先立规矩再逐页改）

先建立 token 与组件层，再逐个页面套用；**不要边改边发明新样式**。

12. **色彩叙事**（当前问题：绿+蓝紫+橙+金各说各话，accent token 闲置）：
    - 主绿 = 学习/成长（现有 `--primary` 微调）；**金橙 = 奖励/宝箱/徽章**（统一 `--reward` token）；蓝紫仅用于"外部/进行中"（AI、链接）；灰阶/边框统一；
    - 全站禁止再出现 `#e9f9ef`、`#5b7fff→#8a5cf6` 这类散装色（替换为语义 token）。
13. **图标系统**：新增 `components/Icon.jsx`（内联 SVG，统一 1.5px 圆头线宽、24px 网格）；侧边栏/快捷格/三件事全部换装；emoji 仅保留在文案彩蛋与宠物气泡。
14. **字号阶梯**：定义 Type scale（11/12/13.5/15/18/22/28）与字重用例（标题 700、正文 400、数字 800），消灭 10.5px 微字与 `font-weight: 800` 滥用。
15. **组件样板**：卡片（16px 圆角、1px 边框、统一阴影、hover 抬升）、按钮体系（主/次/幽灵）、进度条、chip、空状态插图、**RewardToast 统一奖励反馈**（+XP/+币/徽章/上限提示全站一个组件）。
16. **逐页美化清单**（按用户感知排序）：
    - 首页 hero：去掉两团模糊装饰圆，改为"渐隐光晕+网格纹理"或干脆极简；宠物与 hero 文案排版对齐网格；XP/连击 chip 改为卡片化徽章；
    - 成就页：等级卡 → 宠物大图+词霸称号的"主角位"；徽章墙 3 列→响应式（桌面 4-6 列、移动 3 列）；图鉴区块 → 套卡墙入口卡片（不再是一根孤零零的进度条）；
    - PetMascot：SVG 圆润化、眨眼/漂浮动画（CSS keyframes）、心情表情差异放大——它是全站情感锚点，值得单独一版；
    - 训练/复习/测验：正确/错误反馈、组合特效样式统一（克制、不眩目）；
    - 全局动效节奏：升级全屏动画、进化动画、开箱动画已有一版，统一缓动曲线与时长。
17. **验收标准**：同一页面截图对比；`globals.css` 中散装色号 grep 为零；所有 emoji 图标替换为 Icon 组件后页面无布局抖动；新 UI 在 375px 移动宽度下无横向滚动。
