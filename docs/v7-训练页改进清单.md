## 二、借开源项目

| 来源 | 值得借鉴 | 落到我们 |
| --- | --- | --- |
| **qwerty-learner**（打字背词爆款） | "敲出单词"的沉浸输入 = 拼写模式即游戏 | 训练「听写」模式增强为**键盘拼写输入**（显示音节下划线，拆词根音节，输错抖动）——复用我们既有听写判分逻辑 |
| qwerty-learner | 词库按 场景/难度 切换的轻体验 | 我们按教材单元 ✓（已对齐，不学它全场景） |
| **wordpecker**（Duolingo 式个人课程） | 个人词表 + 自动出题 | 个人词表已删（用户拍板）；保留教材词库出题 ✓ |
| **ling**（SRS 卡片流） | 卡片/选择交替的混合题型节奏 | 「今日模式」可**混搭题型轮换**（选中文→闪卡→拼写，每题随机），避免单一模式疲劳——🟡 P2 可选项 |
| 通用 | 错误词 SRS 状态可视化 | 完成页错词行显示「稍后 10 分钟 / 明日」复习时间提示（memory 已有 due 数据，纯展示）🟢 P1 |

## 三、增删改查汇总（针对训练页现状）

**增**
1. 「快速复习 5 题」入口（P2）
2. 完成页「错词自动再战 · 3 题」迷你轮（P1）
3. 完成页错词行显示 SRS 复习时间点（P1）
4. 今日模式混搭题型轮换（P2，可选项）

**删**
1. ✅（已删）我的词表
2. 自定义设置区「词条类型」「题量」收回**「高级设置」折叠**（默认不展开）——首屏只剩 年级 + 范围（P1）
3. 「听力」模式描述与「听写」区分文案修正（小）

**改**
1. 答完自动进下一题（P0）
2. GameBar XP 即时跳动（P0）
3. 连击提示位置：从顶部居中 toast 改为题目卡附近轻章（避开自动前进切换导致 toast 残留）（P1）
4. 听写模式 → 键盘拼写输入增强（音节线/抖动反馈）（P2）

**查**
1. 训练历史（每日答对/连击/消灭）进 stats 页（远期）
2. 本轮薄弱词清单（done 已有 wrongPool，加"复习时间点"列）

## 四、建议执行顺序

| 批次 | 内容 | 性质 |
| --- | --- | --- |
| **甲（手感核心，0.5 天）** | 自动进下一题 + XP 即时跳动 | 最像多邻国、收益最大、风险最低 |
| **乙（设置简化 + 错词闭环，0.5 天）** | 高级设置折叠 + 错词自动再战 + SRS 时间提示 | 简化 + 强化消灭循环 |
| **丙（入口增强，0.5 天）** | 快速复习 5 题 + 连击章位置调整 | 每日入口更丰富 |
| **丁（远期可选项）** | 键盘拼写输入、题型混搭、训练统计 | 大改，单列评估 |

> 教训注记：多邻国 2024 道路图改版流失事件提醒我们——训练内页的功夫下在"手感"（自动前进/即时反馈/节奏），不做伤筋动骨的版面重构；当前纸墨内核保持稳定。
